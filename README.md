# Play Mode

Play Mode makes interactive projects that let people experience an idea: games, 3D worlds and small experimental tools, each built around a story.

Start with a story, then work out which medium tells it best. Not every project is a game, and not every project is Unity.

## This repo

A minimal Next.js placeholder for playmode.ca. Individual projects will live in their own folders or repos.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
npm run typecheck
```

Copy `.env.example` to `.env.local` to override `NEXT_PUBLIC_SITE_URL`.
